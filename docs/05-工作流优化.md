# 05 · 工作流优化（多智能体方法论）

> 找和我们工作流（编排 + 监督）相似的多智能体方法论文，看能否优化编排本身（2026-08）。

## 找到的 3 个方法论来源

1. **VMAO: Verified Multi-Agent Orchestration**（ICLR 2026，arXiv 2603.11445）
   把复杂问题拆成 **DAG 子问题 → 并行执行 → LLM 验证器查完整性 → 自适应 replan 补缺口**；
   带可配置停机条件（质量 vs 成本）。结果：完整性 3.1→4.2、来源质量 2.6→4.1（对比单智能体）。

2. **Anthropic 多智能体协作模式**（官方指南）
   - Pattern1 **Evaluator-Optimizer**：生成 → 验证 → 反馈 → 重试，循环到通过或达上限。
   - Pattern2 **Orchestrator-Subagent**：就是我们现在这套（DSH 编排 + 子智能体干活）。
   - 关键警告：**验证器只有标准明确才有用，否则只是橡皮图章**；循环必须设最大次数 + 兜底（升级给人）。

3. **ICML 2026「重新认识 Orchestrator / 过程评估」**
   要评估的是**编排过程本身**（路由、提示词、分工是否合理），而不只是最终产出。

## 对我们工作流的 6 条优化

| # | 优化 | 来源 | 说明 |
|---|------|------|------|
| 1 | **Verify→Replan（不是简单回改）** | VMAO | 监督不过时，DSH 重新拆解缺口、重新路由，而不是让工人"再改一下" |
| 2 | **加 Learn 环节** | MASFly/Reflexion | 每次失败记"哪里错+为什么+怎么改"进 workflow 记忆，下次提示词直接避开 |
| 3 | **最大重试 + 升级给人** | Anthropic | 验证最多 2~3 轮，仍不过就停下来问你，防空转 |
| 4 | **验收用打分表，不是"合不合格"** | Anthropic | 08 模板已列检查项，再补"每项 0/1 打分 + 通过线"防橡皮图章 |
| 5 | **独立子任务并行** | VMAO | 多篇笔记、笔记+PPT 素材准备等无依赖步骤并行跑（DAG） |
| 6 | **过程评估** | ICML 2026 | 定期回看 DSH 的路由/提示词命中率，优化"该派给谁"的规则 |

## 落地优先级

- 立即：#4（08 模板改打分表）、#3（加最大重试 + 升级）
- 下一步：#2（workflow 记忆）、#1（replan 语义）
- 视需要：#5（并行）、#6（过程评估）
