# 08 · 研究项目工作流（GPT 思考 + Claude 审计 + hermes 写码 + Claude Code 报告）

> 用户重申的流程（2026-08，长期生效）。**所有方案调研/思考/形成，都用 GPT 思考模式 + Claude max 功率。**

## 六步流程

1. **GPT 提方案**（思考模式）：DSH 根据用户的问题/需求 → 问 GPT → 得到方案。
2. **Claude 审计**（max 功率）：Claude 审计方案——需不需要优化、哪里可改进。
3. **用户审核**：用户过目，拍板通过 / 修改。
4. **hermes 写码 + 跑码**：DSH 写提示词 → hermes 创建项目文件夹、按要求写代码、跑代码；写码/跑码有问题 → hermes 反馈给 GPT → GPT 出解法 → 继续。
5. **Claude Code 报告**：跑完根据实验结果写提示词 → Claude Code 制作报告（**可编辑优先**）。
6. **全程检查**：网页 GPT/Claude 负责全程结果检查（打分表见 `templates/08`）。

## 角色分工

| 角色 | 干什么 |
|------|--------|
| GPT（网页·思考模式） | 提方案、写码/跑码遇到问题时的解法 |
| Claude（网页·max） | 审计方案、审计结果、全程检查 |
| 用户 | 审核方案（步骤 3 的关卡） |
| hermes | 创建项目文件夹、写代码、跑代码 |
| Claude Code | 根据实验结果生成报告（可编辑） |
| DSH（我） | 组织编排、写提示词、验收 |

## 额度规则

- 网页模型额度耗尽 → 读恢复时间 → **自动等，不询问用户**（见 `index/工作流记忆.md`）。
- 各模型额度独立（GPT / Claude / Gemini 各自算），一个用完可换另一个。
