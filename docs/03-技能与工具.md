## 2. 各智能体调用方式（落地编排时用）

> ✅ **做法（2026-09 用户明确要求）**：**开一个可见的终端窗口**，在里面把 hermes / Claude Code 唤醒，
> 像问人一样把任务交代给它们。DSH 不要试图后台无人值守地 shell 调用它们。
> 让它们看文件时**直接给绝对路径**（Claude Code 给 Windows 路径，hermes 给 `/mnt/c/...` 路径）。
> 详见 `skills/multiagent-web-collab.md` 的「派活给 hermes / Claude Code」硬规则。

### DSH（我）
- 即本会话，负责编排；找论文用 web_search。

### hermes
- 启动：**开终端窗口** → `wsl -d Ubuntu` 进入 WSL → 输入 `hermes` 唤醒。
- 已核实（2026-09）：发行版名确认为 `Ubuntu`；hermes v0.11.0，位于 `/home/stf/.local/bin/hermes`；交互式 TUI，28 tools / 84 skills，默认模型 `deepseek-v4-pro`；另有非交互 `-z "<prompt>"`。
- 访问 Windows 文件：给 **WSL 绝对路径**，`C:\` 换成 `/mnt/c/`、反斜杠换正斜杠，路径含中文与空格要加引号。
- 写笔记示例路径：`"/mnt/c/Users/我/Documents/Obsidian Vault/记忆/A-Mem.md"`。
- 无沙箱限制，可写 Obsidian Vault。

### Claude Code
- 启动：**开终端窗口** → 直接 `claude`。
- 已核实（2026-09）：`claude` → `C:\Users\我\.local\bin\claude.exe`，`claude --version` → `2.1.216 (Claude Code)`；支持 `claude -p "<prompt>"` 非交互输出。
- 给它的文件用 **Windows 绝对路径**（如 `C:\Users\我\Documents\DEEPSEEK\...`）。
- 模型：deepseek-v4-pro[1m]（1M 上下文，适合大文件/长任务）。
- 可写项目目录、桌面；安装 skill 后做 PPT。
