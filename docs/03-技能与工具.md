## 2. 各智能体调用方式（落地编排时用）

> ⚠ 实测：当前 DSH 沙箱禁止直接执行 `wsl.exe` / `claude.exe`，所以由 DSH 直接 shell 调用不可行；
> 采用「dispatch 文件 + 人工桥接」，详见 `04-落地编排.md`。

### DSH（我）
- 即本会话，负责编排；找论文用 web_search。

### hermes
- 启动：`wsl -d Ubuntu` 进入 WSL，再执行 `hermes`。
- 已核实：发行版名确认为 `Ubuntu`（读注册表 Lxss），`wsl -d Ubuntu` 写法正确。
- 访问 Windows 文件：经 `/mnt/c/Users/我/Documents/Obsidian Vault`（注意路径含中文与空格，命令里要加引号）。
- 写笔记示例路径：`"/mnt/c/Users/我/Documents/Obsidian Vault/记忆/A-Mem.md"`。
- 无沙箱限制，可写 Obsidian Vault。

### Claude Code
- 启动：终端直接 `claude`。
- 已核实：`claude` → `C:\Users\我\.local\bin\claude.exe`（单文件 258MB）；支持 `claude -p "<prompt>"` 非交互输出。
- 模型：deepseek-v4-pro[1m]（1M 上下文，适合大文件/长任务）。
- 可写项目目录、桌面；安装 skill 后做 PPT。
