# 02 · Obsidian 笔记规范

> 2026-08 更新：**不再参考旧笔记风格**，改为简单通俗、带例子；链接仍用 Obsidian 原生 `[[...]]`。

---

## 1. 目录约定

| 目录 | 用途 |
|------|------|
| `记忆/` | **论文笔记、方法笔记、思路/动机想法**（本工作流主要写这里） |
| `笔记/` | 工具型笔记：提示词、常用、论文写作、申博等 |
| `Clippings/` | 网页剪藏（不主动写） |
| 根目录 | 报告正文、审稿、图表 |

> 论文笔记一律进 `记忆/`。方法/思路/动机类笔记也进 `记忆/`。

---

## 2. 命名规则

- 论文笔记：用论文的**常见简称或标题**，英文保留英文，如 `Mem0.md`、`A-Mem.md`、`RAG.md`。
- 长标题含特殊字符时去掉 `:` `/` 等非法字符（你已有笔记用空格替代了冒号，沿用即可）。
- 思路/动机类：短中文名，如 `思路.md`、`动机想法1.md`、`场景.md`、`方法.md`。

---

## 3. 论文笔记模板（简单通俗 + 带例子）

> 2026-08 更新（按你的要求）：**不沿用旧笔记的 frontmatter/固定章节风格**，改为简单通俗、口语化、带例子。

每篇论文笔记就写 5 段，能用一句话例子就举例：

1. **这篇讲了啥** —— 一句话说清
2. **为什么做** —— 动机，讲痛点，别堆术语
3. **怎么做的** —— 方法，分步骤，每步一句话 + 一个小例子
4. **结果咋样** —— 数据集/指标/结论，一句话
5. **一句话带走** —— 组会能直接念

写法示范（非真实论文，仅示意风格）：

> 这篇讲的是怎么让 AI 助手记住用户几周前说过的话。
> 为什么做：普通 RAG 只会按相似度找片段，跨会话的"上周我提过"就找不回来。
> 怎么做：把对话抽成"事件"，每个事件带时间戳和论元，检索时按时间+语义一起找。
> 结果：在 LoCoMo 上多跳召回比朴素 RAG 高不少。
> 一句话带走：用"事件+时间"替代"纯相似度"，解决跨会话记不住。

链接仍写结尾 `[[相关笔记]]`（规则见第 4 节）。

## 4. 建链规则（Obsidian 原生 `[[...]]`）

1. 链接写在**笔记结尾**，紧跟正文，形如 `[[思路]][[动机想法1]][[动机想法2]][[草稿]]`。
2. 链接对象必须是 **Vault 中真实存在的笔记文件名**（不含 `.md`、不含路径）。
3. 链接由 **DSH 读 Vault 后判定**，生成清单交给 hermes 写入；不猜、不造。
4. 链接要“双向”才有效：新建笔记里 `[[Mem0]]`，同时可在 `Mem0.md` 结尾补回 `[[新笔记]]`
   （由 DSH 决定是否补，避免每篇都去改旧笔记造成噪音）。
5. 链接分类（按**真实存在**的笔记整理，快照 2026-08）：
   - 主题类：`[[长期记忆]]`、`[[为什么需要记忆]]`、`[[多智能体]]`、`[[RAG]]`、`[[场景]]`、`[[方法]]`、`[[复杂多跳长程推理任务]]`、`[[长对话场景下的记忆管理]]`、`[[子空间论文总结]]`
   - 论文类（必须用**完整真实文件名**）：`[[Mem0]]`、`[[A-Mem]]`、`[[CONDIGRAPH]]` 等；长英文标题整段照抄，如 `[[AMemAgentic Memory for LLM Agents  NeurIPS 2025]]`
   - 思路/草稿类：**当前不存在**，见下方第 6 条“当前断链”。

6. ⚠ 当前断链（已核实）：
   - `Mem0.md`、`A-Mem.md` 结尾的 `[[思路]] [[动机想法1]] [[动机想法2]] [[草稿]]` 全部指向**不存在的笔记**。
   - 处置：见 `index/关系索引.md` 的“建链方案”——要么创建这 4 个容器笔记，要么改链到真实主题笔记。

---

## 5. 图片

- 截图放同目录（`记忆/`），用 `![[xxx.png|宽度]]` 嵌入，如 `![[Pasted image 20260428161717.png|679]]`。
- 已知缺失图片（断链）：`fig 1.png`、`fragment_memory_scenario.svg`。**按你的要求不处理**，仅记录。
- hermes 写笔记时若你给了图，按此嵌入；没有图则不硬塞。
